# codehorn

## 1. Description
**codehorn** is an enterprise-grade, cloud-native online coding and competitive programming platform inspired by LeetCode. Built using a reactive Spring Boot microservices architecture, MongoDB polyglot persistence, isolated Docker container sandboxing, and a Next.js / Monaco Editor frontend, codehorn enables software developers to solve algorithmic challenges, execute code against test cases in real-time, view submission metrics, track daily streaks, and analyze activity heatmaps.

---

## 2. Technical Special Aspects
- **Decoupled Microservices Infrastructure**:
  - **Gateway Service**: Spring Cloud Gateway with Consul service registration and strip-prefix routing.
  - **Auth & User Services**: Reactive Spring WebFlux with Kotlin Coroutines handling JWT authentication, profile stats, streaks, and activity heatmaps.
  - **Problems & Submission Services**: MongoDB document store for problem catalogs, starter templates, canonical reference code, and submission histories.
  - **Code Execution & Language Runners**: Ephemeral Docker-in-Docker (DinD) sandbox execution microservices supporting C++, Java, Python, and JavaScript.
- **Isolated Sandbox Execution Engine**: Secure code execution with resource boundaries (memory/CPU limits, execution time caps, 2-minute safety watchdog) using custom STDIN/STDOUT stream serialization and testcase parsers (`CodehornTestcaseParserStrategy`).
- **Interactive Web IDE Frontend**: Next.js client with integrated Monaco Editor, multi-language starter template switching, dark modern glassmorphism UI, real-time submission status badges, and runtime/memory profiling charts.
- **GitOps Infrastructure as Code**: Production deployment automation using Terraform scripts, Helm packaging, and ArgoCD continuous delivery on GKE and AWS EKS.

## 3. Technologies Used
- **Backend**: Spring Boot 3/4, Spring WebFlux, Spring Cloud Gateway, Consul Service Discovery, Kotlin Coroutines, Java
- **Database**: MongoDB, Spring Data MongoDB Reactive
- **Execution Sandboxing**: Docker, Ephemeral Container Isolation, Shell Scripts
- **Frontend**: Next.js, React, TypeScript, Monaco Editor, Vanilla CSS
- **Build System**: Gradle multi-project build
